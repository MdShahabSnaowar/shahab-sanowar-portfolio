# Shahab Two-Page Django Portfolio

Two-screen portfolio based on the supplied reference:
1. Django/Python CLI intro
2. Dark space-themed hero with teal accents and hooded robot

## Run
Open a terminal in this folder:
```bash
npm install
npm run dev
```

For this static version, no Node/Vite is required. You can also simply open `index.html`.
If you have your resume PDF, place it beside index.html as:
`Shahab_Sanowar_Resume.pdf`
